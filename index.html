使用说明

1. 使用 Chrome / Edge 打开本页（WebHID 需要 Chromium 内核，file:// 或 https 均可）。
2. 点"连接设备"，弹窗选择 VID=0x1919 PID=0x1919 的键盘。
3. 若 C# 工具同时打开了设备，先关闭它再连接。
4. 心跳：设备通过 0xBD 报告周期上报，连接后状态点变绿表示在线。
5. 协议帧：0xAA(主) / 0x55(响应) + flag|cmd + offset(BE) + index + len + data，无校验。
6. 所有功能与 C# 版 usbdev 对齐：数据通信 / 设备配置 / 改键 / 灯效 / 宏 / OTA。
